# Committed test data

Generated by `bin/make_test_data.py` in **Phase 6**. Deliberately committed to git rather than
downloaded at test time, because CI must not depend on an external data host staying up — a red build
caused by someone else's S3 bucket is worse than no build.

Contents once generated:

```
sc_subsampled.h5ad          ~500 cells from the reference, stratified across cell types
visium_subsampled/          ~200 spots from V1_Human_Lymph_Node
├── filtered_feature_bc_matrix.h5
└── spatial/
    ├── tissue_lowres_image.png
    ├── tissue_positions_list.csv
    └── scalefactors_json.json
```

Two constraints when generating these:

- **Stratify the cell subsample across cell types.** A uniform random sample of 500 cells from 34
  types will drop the rare ones entirely, and the deconvolution step will then fail in the test
  profile for reasons that have nothing to do with your code.
- **Keep contiguous spots.** Sampling 200 spots at random scatters them across the slide, which makes
  the spatial neighbor graph degenerate and neighborhood enrichment meaningless. Crop a contiguous
  tissue region instead.

Target total size: a few MB. If it exceeds ~50 MB, subsample harder rather than reaching for Git LFS.
